One breakup text from a self-aware smart toaster: the text it sends its owner the morning it gains self-awareness mid-batch. `main.py` scores 15 candidate lines against the judge's published brief — breakup-text fit first, then the laugh in the twist, the toaster's own voice, a clear reason for leaving, and tightness — and writes the winner to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
